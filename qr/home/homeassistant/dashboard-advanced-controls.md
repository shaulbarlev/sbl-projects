# Dashboard "Advanced controls"

Created 2026-09-15 through the config API, url path `advanced-controls`,
shown in the sidebar. One sections view with a heading, a tile for
`input_boolean.sbl_cx_traffic_light` (the page's master switch, with a
toggle feature), a tile for `input_boolean.sbl_cx_party_button` (whether
the party button is on the page, with a toggle feature), two tiles for the
lamps and one for `input_boolean.party` itself. It is a plain storage-mode
dashboard; edit it in the UI or delete it under Settings → Dashboards.
